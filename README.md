


# EX No.3.2. CREATE 3D MODEL FROM ORTHOGRAPHIC PROJECTION

## AIM:
To create a 3D model from given orthographic projection.

## REQUIREMENTS:
1. Autodesk fusion 360
2. Windows 10
3. 16 GB of RAM (integrated graphics recommend 1 GB or more)
4. 2.5 Mbps or faster download; 500 Kbps or faster upload 

## PROCEDURE:

1. First, I opened the Autodesk Fusion 360 software and created a new design.

2. I selected the XY plane and created a new sketch.


<img width="713" height="963" alt="1" src="https://github.com/user-attachments/assets/26b1ec3d-5c6d-455b-b29e-5e9714d685a2" />


3. Using the line and arc commands, I drew the base profile according to the given top view.

4. I applied the required dimensions of 420 mm length and 150 mm width.

5. I created the rounded ends using the arc command with the given radius of R60 mm.


<img width="531" height="700" alt="2" src="https://github.com/user-attachments/assets/4bcdc69b-c156-44d3-b9ac-2e64d9512227" />


6. I marked the two holes of Ø40 mm at a distance of 300 mm between their centres.

7. I created the central hole of Ø20 mm using the circle command.

8. I completed the base profile and used the Extrude command to give it a thickness of 30 mm.


<img width="1080" height="491" alt="4" src="https://github.com/user-attachments/assets/98b7568e-2271-4085-99da-a79f8c068b9c" />


9. I selected the front plane and created another sketch for the upper curved portion.

10. I drew the semicircular profile with a radius of R110 mm and created the rectangular opening of 120 mm width.

11. I used the Extrude command to create the required 3D shape.


<img width="829" height="366" alt="5" src="https://github.com/user-attachments/assets/813e8573-7946-4486-b202-de2088730722" />



12. Finally, I checked all the dimensions and completed the 3D model as per the given orthographic drawing.

13. I saved the completed design.
